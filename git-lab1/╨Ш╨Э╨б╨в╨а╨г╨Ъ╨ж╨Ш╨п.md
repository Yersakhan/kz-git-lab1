# Лаб. работа 1: Работа с коммитами в Git

Все файлы уже готовы в папке `files`. Сайт на казахском: открой `index.html` в браузере, чтобы увидеть результат. Файлы не нужно писать самой, только копировать и выполнять команды.

Копировать: открой нужную папку `files\stepN-...`, выдели файлы (Ctrl+A) и перетащи в папку `my-commit-repo` (в VS Code в Explorer или в обычном проводнике).

## 1. Подготовка
В терминале VS Code (Ctrl+`) перейди в место, где хочешь создать проект (например `cd C:\`), затем:
```
git init my-commit-repo
cd my-commit-repo
code .
```
(`code .` откроет папку в VS Code; дальше терминал открой там же.)
Скопируй в папку файл из `files\step1-readme` (README.md), затем:
```
git add README.md
git commit -m "Initial commit with README"
```
Если Git просит имя и почту:
```
git config --global user.name "Твоё Имя"
git config --global user.email "твоя@почта.com"
```
и повтори commit.

## 2. Создание коммитов
Скопируй `files\step2-index\index.html`, затем:
```
git add index.html
git commit -m "Add basic index.html file"
git status
```
Скопируй `files\step3-style\style.css`, затем:
```
git add style.css
git commit -m "Add basic styles for the project"
```

## 3. История
```
git log --oneline
git log
git show <hash>
```
(вместо `<hash>` вставь короткий код любого коммита из `git log --oneline`).

## 4. Изменение последнего коммита (amend)
Замени `index.html` файлом из `files\step5-amend` (в нём добавлена строка «Келгеніңізге рақмет!»), затем:
```
git add index.html
git commit --amend -m "Updated index.html with thank you message"
git log --oneline
```

## 5. Откат коммита
```
echo "This is an error file" > error.txt
git add error.txt
git commit -m "Mistakenly added error.txt"
git log --oneline
git reset HEAD~1
git status
```
(`HEAD~1` — то же, что `HEAD^`, но работает в любом терминале.)

Дальше в задании ошибка: после `rm error.txt` команда `git add .` ничего не добавит, и `git commit` скажет `nothing to commit`. Поэтому выполни так:
```
rm error.txt
git add .
git commit --allow-empty -m "Removed mistakenly added error.txt"
```

## 6. Восстановление файла
Скопируй `files\step7-about\about.html`, затем:
```
git add about.html
git commit -m "Added about.html file"
rm about.html
git rm about.html
git commit -m "Deleted about.html"
git checkout HEAD~1 about.html
git add about.html
git commit -m "Restored about.html file"
git log --oneline
```

## 7. Отправка на GitHub (по желанию)
Создай на github.com пустой репозиторий и выполни (ссылку возьми со страницы репозитория):
```
git remote add origin https://github.com/ТВОЙ_ЛОГИН/my-commit-repo.git
git branch -M main
git push -u origin main
```
