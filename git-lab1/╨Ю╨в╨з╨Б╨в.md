## Выполненные команды

| Команда | Что делает |
|---|---|
| `git init my-commit-repo` | создаёт новый локальный репозиторий |
| `git add <файл>` | добавляет файл в индекс (готовит к коммиту) |
| `git commit -m "..."` | создаёт коммит с сообщением |
| `git status` | показывает состояние репозитория |
| `git log --oneline` | краткая история коммитов |
| `git log` | подробная история коммитов |
| `git show <hash>` | показывает изменения конкретного коммита |
| `git commit --amend -m "..."` | изменяет последний коммит |
| `git reset HEAD~1` | отменяет последний коммит, сохраняя файлы |
| `rm <файл>` | удаляет файл с диска |
| `git rm <файл>` | удаляет файл и фиксирует удаление в индексе |
| `git checkout HEAD~1 <файл>` | восстанавливает файл из предыдущего коммита |

## Возникшие проблемы и решение
1. После `git reset` и удаления `error.txt` команда `git commit` выдала `nothing to commit`, потому что `error.txt` уже не отслеживался. Решение: `git commit --allow-empty -m "Removed mistakenly added error.txt"`.
2. (если Git просил имя и почту) Ошибка `Author identity unknown`. Решение: задать `user.name` и `user.email` через `git config --global`.
